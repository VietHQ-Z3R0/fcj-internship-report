# AWS Savings Plans – 28/10/2026

AWS Savings Plans provide a flexible pricing model that allows organizations to reduce compute costs by committing to a consistent hourly usage amount over a one- or three-year period. In exchange, eligible compute usage receives discounted pricing compared to On-Demand rates. This offers an opportunity to optimize long-term infrastructure expenses while maintaining flexibility in how compute resources are used.

**Key points to know:**

- AWS Savings Plans require a commitment to a specific amount of compute spending per hour (USD/hour) over a one- or three-year term.
- **Compute Savings Plans** provide flexibility across Amazon EC2, AWS Fargate, and AWS Lambda, including changes to instance families and AWS Regions.
- **EC2 Instance Savings Plans** provide discounts for a specific EC2 instance family within a selected Region, generally offering higher savings with less flexibility.
- Savings Plans automatically apply discounted rates to eligible usage, but unused commitments still incur charges.
- AWS Cost Explorer provides Savings Plans Coverage and Utilization reports to help organizations evaluate how effectively their commitments are being used.
- Savings Plans Recommendations use historical usage patterns to suggest suitable commitment levels, although future workload changes should also be considered.

This pricing model is especially useful for organizations running workloads with predictable baseline compute demand, allowing them to reduce long-term infrastructure costs while keeping variable workloads flexible through On-Demand pricing.
